## 架構決定

```
SakiDive repo(資料引擎,有 GEMINI_API_KEY secret)
  ├ 每天 10:00 JST  enrich_content.py  路線圖挑一題 → 寫一篇 md(含 frontmatter)
  ├ 每天 10:30 JST  enrich_spots.py    (新)查證 2 個潛點 → 寫 data/spots/<id>.json(含 1–12 月生物+來源)
  └ 每週一          fetch_brief.py      本機 launchd → 00_每日簡報/

DiveInOut repo(對外網站,不需要任何金鑰)
  └ 每天 11:30 JST  tools/build_site.py (新)
        checkout SakiDive → 產生
          articles/index.json + articles/<slug>/index.html(靜態頁,Google 讀得到)
          assets/covers/<slug>.svg(品牌封面,程式生成)
          news/(每週簡報濃縮)
          spots.json(合併)+ spots/<id>/index.html(每個潛點一頁)
        → commit + push → GitHub Pages
```

時間錯開:SakiDive 10:00 / Sarayuki 11:00 / DiveInOut 建站 11:30(建站不呼叫 Gemini,不吃額度)。
理由:SakiDive 已經有能跑的寫作管線+金鑰,不重做;DiveInOut 只負責把資料變成網頁,repo 不放任何憑證。

## 內容規則(新文章一律適用,一開始就避開 Sarayuki 的坑)

- **正文 800–1400 字**,書面繁中(台灣用語),生活風、新手友善。少於 800 字拒寫入;超過 1600 字也退回重寫一次。
- **禁 AI 腔**:程式內建黑名單,命中就自動重寫一次,第二次還命中就不寫入、留在 log。黑名單初版:至關重要、不容錯過、讓我們一起、總而言之、總之、值得一提的是、在這個…的時代、無論您是…還是…、宛如、彷彿置身、夢幻般、絕佳、一站式、深入探討、揭開…的面紗、不僅…更是…、賦能、打造、開啟…之旅、潛水愛好者們、親愛的。也不用「您」,用「你」。
- **每篇都有封面**:程式生成的 DiveInOut 品牌封面(SVG,深海漸層+分類圖示+標題),**不抓他人照片**。
- 來源:正文最後一段「來源」列出 grounding 網址;正文內不再每句塞 `[來源 N](超長網址)`,改成句尾上標數字 `¹²`。Facebook / Reddit 不當來源。
- 時效資訊(價格、季節、規範)標 `⚠️需覆核`。
- 舊的 22 篇:先原樣上架,標「深度攻略」,來源連結收進文末摺疊區;不重寫(要重寫另排)。

## 潛點資料站設計

**地區兩層**:`country`(日本/台灣/菲律賓/印尼/馬來西亞/泰國/帛琉/馬爾地夫…)→ `area`(沖繩本島、慶良間、宮古、石垣、與那國、伊豆、小笠原、墾丁、綠島、蘭嶼、小琉球、東北角、宿霧、薄荷、杜馬蓋地、科隆、阿尼洛、峇里、四王群島、科莫多、仙本那、詩巴丹、斯米蘭、濤島…)。選「沖繩」= 列出沖繩所有 area 的所有潛點。

**每個潛點一頁** `spots/<id>/`:基本卡(位置/程度/入水/最佳月份/水溫/能見度)、**1–12 月生物月曆**(格子圖,點月份看那個月可能遇到的生物,連到生物圖鑑)、介紹文(來自每日文章)、注意事項、來源與最後查證日、同 area 其他潛點。

**排名(不能憑空捏造)**:SS 要「熱門排名」,但我們現在**沒有任何真實熱門數據**(沒有流量統計、沒有評論數)。所以分兩段:
1. **現在:「DiveInOut 推薦指數」**,0–100,公式公開寫在排名頁,每個潛點頁顯示分數拆解:
   - 生物多樣性 30(月曆裡出現的物種數)
   - 可潛季節長度 20(最佳月份數)
   - 新手友善 20(beginner 20 / intermediate 12 / advanced 5)
   - 招牌生物 20(鬼蝠魟、鯨鯊、海龜、翻車魚、錘頭鯊,每種 +5,上限 20)
   - 資料可信度 10(來源數 ≥3 且 180 天內查證過才滿分)
   - 不設「編輯加分」,避免看起來像收錢排名。
   - 可切換「沖繩內排名」「新手排名」「12 月排名」(月份排名=該月有出現的生物數)。
2. **之後:「本站熱門」**,接無 cookie 的流量統計(建議 GoatCounter 免費版或 Cloudflare Web Analytics)累積 30 天後,用潛點頁瀏覽數排。在那之前頁面不寫「熱門」兩個字。

**潛點擴充(亞洲每個潛點)**:不讓 Codex 或 AI 憑記憶亂補。新增 `enrich_spots.py`(SakiDive repo):每天從 `data/spot_queue.md` 挑 2 個,用 Gemini + Google Search grounding 查證,輸出結構化 JSON(座標、程度、入水、月份、1–12 月生物、來源 ≥2),寫入 `data/spots/<id>.json`。缺來源的欄位留空,不猜。第一批佇列約 120 個亞洲潛點 → 約 2 個月補完;現有 30 點優先(補月曆)。

**整合既有資料**:
- `creatures.json` 每種生物已有 `spots[]` → 轉成月曆初稿的「可能出現」(沒月份資訊的標「全年/月份未確認」)。
- 22 篇攻略裡已有的季節段落(例如慶良間「冬季 1–3 月座頭鯨」)→ `enrich_spots.py` 讀對應 md 當第一手素材,查證後寫進月曆。
